“I can filter by source type or person, search records, open a conversation, and inspect the source evidence behind its route and next step. Missing text stays visible as an intake/review exception; I do not invent a summary when no transcript was supplied.”

“Now I’ll reset the demo. I import the initial batch and the unique record count is 44. I’ll import it again in reverse order. The same source_type/source_id identities and revision rules prevent duplicate activity; the count stays 44. I’ll select M07 and save a manual route. Now I apply the later update. The revised transcript becomes visible, but the record count remains 44 and my manual route is preserved. The analysis is flagged for review because the source text changed.”

2:35–3:00 — Export and close
“Finally, Export current state downloads a JSON bundle and CSV manifest. Each manifest row points to a generated output path and records revision, route, review state, manual override and analysis freshness. The main trade-off is that routing is deterministic and reviewable, rather than pretending to be a live AI model.”
